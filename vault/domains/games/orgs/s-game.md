# S-GAME

Studio et éditeur de jeux vidéo indépendant basé à Pékin (Chine), fondé par Qiwei Liang (alias « Soulframe »). Connu pour la franchise *Rainblood* / *Phantom Blade*, notamment l'action-RPG *Phantom Blade Zero*.
