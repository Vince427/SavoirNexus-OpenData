# Rust

Dans Rust, le seul but est de survivre. Sur cette le, tout ce qui vous entoure est une menace : la faune, la nature, les autochtones, sans oublier les survivants eux-mmes. Il ne vous faudra reculer devant rien, si vous voulez voir un nouveau jour se lever.
